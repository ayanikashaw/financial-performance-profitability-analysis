# Financial Performance & Profitability Analysis

## Project Overview

This project analyzes the financial performance of Tata Consumer Products using historical financial data. It looks at sales, profit, profitability margins, expenses, EPS, and cash flow to understand the company's financial performance over time.

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis Done

- Sales and profit analysis
- Profitability margin analysis
- Expense ratio analysis
- EPS trend analysis
- Year-over-year growth analysis
- CAGR analysis
- Cash flow analysis
- Business insights

## Key Findings

- Sales increased by 107.58% from 2012 to 2023.
- Net profit increased by 216.55% from 2012 to 2023.
- Net profit CAGR of 11.04% was higher than sales CAGR of 6.86%, indicating improved profitability.
- Net profit margin improved from 6.28% in 2012 to 9.58% in 2023.
- Operating cash flow reached its highest level of ₹1,656 crore in 2021.
- Net cash flow was negative ₹796 crore in 2022, mainly due to higher investing and financing cash outflows.

## Dataset

The project uses the Detailed Financials Data of NSE & BSE Companies dataset from Kaggle.
